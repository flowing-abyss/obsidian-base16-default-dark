## Maximize Your Setup

### Recommended Fonts

Elevate the theme with professional typefaces built for readability and visual hierarchy: **IBM Plex Sans**, **IBM Plex Serif**, **IBM Plex Mono**, and **Noto Color Emoji**.

1. Install **[Local Fonts](https://github.com/flowing-abyss/obsidian-local-fonts)** from Community Plugins.
2. Download the [prebuilt font pack](https://flowing-abyss.com/local-fonts.zip) and unzip it into a `fonts` folder in your vault root.
3. In *Settings → Local Fonts*, assign each role:

| Role | Font |
|---|---|
| Text / Interface | IBM Plex Sans |
| Headings | IBM Plex Serif |
| Monospace | IBM Plex Mono |
| Emoji | Noto Color Emoji |

No CSS snippets, no `!important` hacks — fonts load straight from your vault.
